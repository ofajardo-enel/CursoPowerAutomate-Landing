Bienvenida y objetivos

Power Automate permite automatizar tareas y procesos repetitivos conectando diferentes aplicaciones y servicios, aumentando productividad y estandarización.

✅ Objetivo principal
  • Automatizar tareas y procesos repetitivos dentro de una organización.
  • Conectar apps/servicios (Microsoft 365 y otros) para flujos end-to-end.
🧩 ¿Qué es Power Automate?
  • Herramienta para automatizar flujos repetitivos.
  • Integra apps como Outlook, Teams y SharePoint.
  • Soporta usuarios de negocio y desarrolladores.
🎤 Guion rápido: pide 2 ejemplos de aprobaciones (contratos, compras, permisos) y anota cuáles conectores usarían.

Tipos de flujos (Power Automate)

En el curso se trabajan tres categorías: automatizados, instantáneos y programados.

Automatizados

Se activan por un evento (ej. “cuando se cree un ítem”).

Instantáneos

Se ejecutan manualmente por botón (ideal para “alta rápida”).

Programados

Se corren por horario/intervalo (recordatorios, rutinas).

🧠 Regla práctica (sugerida)
  • Evento → Automatizado.
  • Usuario dispara → Instantáneo.
  • Reloj → Programado.
🎤 Guion rápido: muestra 1 ejemplo por tipo y pregunta: “¿qué pasaría si lo hicieras con el tipo equivocado?”

Triggers y conectores

Los triggers (disparadores) inician flujos y los conectores enlazan aplicaciones (Outlook, Teams, SharePoint, etc.).

🔔 Triggers (disparadores)
  • Inician el flujo cuando ocurre un evento (creación/modificación, llegada de email, etc.).
  • Buenas prácticas: filtrar temprano para evitar ejecuciones innecesarias.
🔌 Conectores
  • Conectan servicios: Microsoft 365, SharePoint, Teams, Excel Online, Power BI, etc.
  • Define permisos (cuentas/conexiones) y alcance de datos.
🧪 Mini-demo sugerida (5 min)
  • “When an item is created” (SharePoint) → “Send an email” (Outlook).
  • Agrega condición por “Estado = Pendiente”.
🎤 Guion rápido: recalca “trigger correcto + filtro temprano = menos ruido + mejor performance”.

Laboratorios prácticos con SharePoint (paso a paso)

Laboratorios basados en el curso: listas/bibliotecas, aprobaciones, recordatorios desde Excel Online y actualización de dataset Power BI.

🧪 Lab 1 — Alta de registros en lista + adjuntos + notificación
  • Crear lista en SharePoint (columnas: Título, Estado, Responsable, Fecha límite).
  • En Power Automate: crear Automated cloud flow con trigger “When an item is created”.
  • Acción: “Get attachments” + “Get attachment content”.
  • Guardar adjuntos en biblioteca (acción “Create file”).
  • Enviar email/Teams con link al ítem y a la carpeta del documento.
  • Agregar control de errores: scope “Try/Catch” (sugerido).
🎤 Tip: pide que 1 participante cree un ítem y otro valide que le llegó la notificación.
🧪 Lab 2 — Aprobación de documentos en biblioteca
  • Crear biblioteca “Contratos” (metadatos: Área, Monto, Estado).
  • Flow automatizado: trigger “When a file is created (properties only)”.
  • Acción “Start and wait for an approval”.
  • Si aprueba: actualizar metadato Estado=“Aprobado” y mover a carpeta “Aprobados”.
  • Si rechaza: Estado=“Rechazado” + notificar al autor con comentarios.
🎤 Tip: muestra la tarjeta de aprobación en Teams/Outlook y cómo queda el audit trail.
🧪 Lab 3 — Recordatorios programados de vencimientos (Excel Online)
  • En SharePoint: archivo Excel “Contratos.xlsx” con columnas: Contrato, Responsable, Vence, Email.
  • Flow Scheduled: diario (o cada X horas).
  • Acción “List rows present in a table”.
  • Filtrar vencimientos (ej. hoy+7 días) y enviar recordatorio.
  • Opcional: escribir una columna “Último aviso” para evitar duplicados.
🎤 Tip: enseña filtro OData vs condición y por qué OData reduce carga.
🧪 Lab 4 — Actualizar dataset de Power BI
  • Pre-requisito: dataset publicado en Power BI con refresh habilitado.
  • Flow instantáneo o programado (según caso).
  • Acción Power BI: “Refresh a dataset”.
  • Notificar resultado al canal de Teams (éxito/error).
  • Opcional: registrar ejecución en una lista “Ejecuciones” (SharePoint).
🎤 Tip: conecta esto con gobierno: inventario de flujos + logging.

Módulo AI Hub y AI Builder

Se introduce el módulo AI Hub y AI Builder para integrar modelos de IA en flujos; incluye un laboratorio para capturar textos de PDFs o imágenes.

🤖 ¿Qué veremos?
  • Dónde encontrar AI Hub en Power Automate.
  • Modelos preconstruidos vs personalizados.
  • Lab: extracción de texto (PDF/imagen) y envío a SharePoint/Teams.
🧪 Lab sugerido — Extraer texto y crear registro
  • Trigger: manual (Instant flow) con carga de archivo.
  • Acción AI Builder: OCR / extracción.
  • Guardar resultado en lista (campo “Texto extraído”).
🎤 Tip: cierra con un ejemplo real (actas, facturas, contratos) y menciona consideraciones de datos.

Gobierno y buenas prácticas

El curso incluye recomendaciones como compartir flujos, documentar técnicamente, y llevar inventario de flujos.

🧭 Checklist de buenas prácticas
  • Compartir flujos para evitar único propietario.
  • Documentación técnica (paso a paso).
  • Inventario simple de flujos (Excel o lista).
  • Uso de ambientes/soluciones (sugerido) para control.
  • Versionado y registro de cambios.
🎤 Tip: pide que elijan 1 práctica para adoptar “desde mañana”.

Automatización de reportes SAP mediante Scripts

Se cubre la automatización de reportes SAP usando scripts grabados, con lineamientos para creación y gestión.

🧩 Conceptos clave
  • Automatización reduce tiempos y errores en generación de reportes.
  • Scripts grabados ejecutan tareas repetitivas de forma precisa.
  • Lineamientos para gestionar scripts y asegurar consistencia.
🎤 Tip: conecta SAP scripts con Power Automate solo a nivel conceptual (orquestación) y cierra con controles de seguridad.
