Modulo 01

Bienvenida y Objetivos

Power Automate permite automatizar tareas y procesos repetitivos conectando diferentes aplicaciones y servicios

🎯

Objetivo Principal

Automatizar tareas y procesos repetitivos dentro de una organizacion. Conectar apps/servicios (Microsoft 365 y otros) para flujos end-to-end.

🧩

Que es Power Automate?

Herramienta para automatizar flujos repetitivos. Integra apps como Outlook, Teams y SharePoint. Soporta usuarios de negocio y desarrolladores.

🚀

Que Construiras?

Flujos automatizados con SharePoint, aprobaciones, recordatorios inteligentes y conexion con AI Builder para extraccion de datos.

🎤 Guion rapido: pide 2 ejemplos de aprobaciones (contratos, compras, permisos) y anota cuales conectores usarian.
Modulo 02

Tipos de Flujos

Tres categorias principales de flujos en Power Automate

⚡

Automatizados

Se activan por un evento (ej. "cuando se cree un item"). Ideales para reaccionar a cambios en datos.

☝

Instantaneos

Se ejecutan manualmente por boton (ideal para "alta rapida"). El usuario decide cuando disparar.

🕐

Programados

Se corren por horario/intervalo (recordatorios, rutinas). Perfectos para procesos recurrentes.

🧠

Regla Practica

Evento → Automatizado  |  Usuario dispara → Instantaneo  |  Reloj → Programado

🎤 Guion rapido: muestra 1 ejemplo por tipo y pregunta: "que pasaria si lo hicieras con el tipo equivocado?"
Modulo 03

Triggers y Conectores

Los triggers inician flujos y los conectores enlazan aplicaciones (Outlook, Teams, SharePoint, etc.)

🔔

Triggers (Disparadores)

Inician el flujo cuando ocurre un evento. Buenas practicas: filtrar temprano para evitar ejecuciones innecesarias.

🔌

Conectores

Conectan servicios: Microsoft 365, SharePoint, Teams, Excel Online, Power BI, etc. Define permisos y alcance de datos.

🧪

Mini-Demo (5 min)

"When an item is created" (SharePoint) → "Send an email" (Outlook). Agrega condicion por "Estado = Pendiente".

🎤 Guion rapido: recalca "trigger correcto + filtro temprano = menos ruido + mejor performance".
Modulo 04 — Hands-On

Laboratorios Practicos

4 laboratorios basados en listas/bibliotecas SharePoint, aprobaciones, recordatorios y Power BI

1 Alta de registros + adjuntos + notificacion ▼
  • Crear lista en SharePoint (columnas: Titulo, Estado, Responsable, Fecha limite).
  • En Power Automate: crear Automated cloud flow con trigger "When an item is created".
  • Accion: "Get attachments" + "Get attachment content".
  • Guardar adjuntos en biblioteca (accion "Create file").
  • Enviar email/Teams con link al item y a la carpeta del documento.
  • Agregar control de errores: scope "Try/Catch" (sugerido).
🎤 Tip: pide que 1 participante cree un item y otro valide que le llego la notificacion.
2 Aprobacion de documentos en biblioteca ▼
  • Crear biblioteca "Contratos" (metadatos: Area, Monto, Estado).
  • Flow automatizado: trigger "When a file is created (properties only)".
  • Accion "Start and wait for an approval".
  • Si aprueba: actualizar metadato Estado="Aprobado" y mover a carpeta "Aprobados".
  • Si rechaza: Estado="Rechazado" + notificar al autor con comentarios.
🎤 Tip: muestra la tarjeta de aprobacion en Teams/Outlook y como queda el audit trail.
3 Recordatorios programados de vencimientos (Excel Online) ▼
  • En SharePoint: archivo Excel "Contratos.xlsx" con columnas: Contrato, Responsable, Vence, Email.
  • Flow Scheduled: diario (o cada X horas).
  • Accion "List rows present in a table".
  • Filtrar vencimientos (ej. hoy+7 dias) y enviar recordatorio.
  • Opcional: escribir una columna "Ultimo aviso" para evitar duplicados.
🎤 Tip: ensena filtro OData vs condicion y por que OData reduce carga.
4 Actualizar dataset de Power BI ▼
  • Pre-requisito: dataset publicado en Power BI con refresh habilitado.
  • Flow instantaneo o programado (segun caso).
  • Accion Power BI: "Refresh a dataset".
  • Notificar resultado al canal de Teams (exito/error).
  • Opcional: registrar ejecucion en una lista "Ejecuciones" (SharePoint).
🎤 Tip: conecta esto con gobierno: inventario de flujos + logging.
Modulo 05

AI Hub y AI Builder

Integra modelos de IA en tus flujos para extraer datos de PDFs, imagenes y documentos

🤖

Que es AI Hub?

Hub centralizado en Power Automate donde encuentras modelos preconstruidos y personalizados de IA listos para integrar.

📄

Modelos Preconstruidos

OCR, extraccion de entidades, analisis de sentimiento, clasificacion de texto. Sin necesidad de entrenamiento.

🧪

Lab: Extraer texto y crear registro

Trigger manual con carga de archivo → AI Builder OCR → Guardar resultado en lista SharePoint ("Texto extraido").

🎤 Tip: cierra con un ejemplo real (actas, facturas, contratos) y menciona consideraciones de datos.
